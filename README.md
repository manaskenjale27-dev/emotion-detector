# Final Project

IBM Applied AI final project: Emotion Detection using the Watson NLP service and a Flask web application.

The application analyzes user-provided text and returns scores for anger, disgust, fear, joy, and sadness, together with the dominant emotion.

## Run the application

Install dependencies with `python3 -m pip install -r requirements.txt`, then run `python3 server.py` and open `http://127.0.0.1:5000` in your browser.

Note: The required submission repository for this assignment is named `oaqjp-final-project-emb-ai`. This README update does not rename or fork this repository.
